Raddy 是基于 [Cloudflare Pingora](https://github.com/cloudflare/pingora) 构建的
反向代理网关(Rust)。你只需写一份 **Raddyfile** —— Caddyfile 风格的配置 ——
raddy 便负责路由、自动 HTTPS、静态文件、压缩、限流与访问日志,并享有
Pingora 的性能与内存安全。

<CardGrid>
	<Card title="可预测的配置" icon="cursor-click">
		指令严格按书写顺序执行。所见即所执行——没有隐藏的排序表。
	</Card>
	<Card title="自动 HTTPS" icon="lock">
		原生 ACME —— 默认 HTTP-01,或经
		[`dns_challenge cloudflare`](config/directives/#dns_challenge) 走 DNS-01 ——
		SNI 动态证书,开箱即用。
	</Card>
	<Card title="热重载" icon="refresh">
		SIGHUP 原子替换路由快照;连接保持不断。
	</Card>
	<Card title="边缘防护" icon="shield">
		基于可信代理模型识别真实客户端 IP 的限流。
	</Card>
	<Card title="可观测性" icon="chart">
		Prometheus 指标与结构化 JSON 访问日志。
	</Card>
	<Card title="零停机升级" icon="rocket">
		`raddy upgrade` 将监听套接字移交给新二进制,连接零中断。
	</Card>
</CardGrid>
