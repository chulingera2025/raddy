Raddy is a reverse proxy gateway in Rust, built on
[Cloudflare Pingora](https://github.com/cloudflare/pingora). You write a
**Raddyfile** — a Caddyfile-style configuration — and raddy handles routing,
automatic HTTPS, static files, compression, rate limiting, and access logs, with
Pingora's performance and memory safety.

<CardGrid>
	<Card title="Predictable configuration" icon="cursor-click">
		Directives run strictly in write order. What you write is what happens —
		no hidden ordering table.
	</Card>
	<Card title="Automatic HTTPS" icon="lock">
		Native ACME — HTTP-01 by default, or **DNS-01** via
		[`dns_challenge cloudflare`](config/directives/#dns_challenge) — with SNI
		certificates, out of the box.
	</Card>
	<Card title="Hot reload" icon="refresh">
		SIGHUP swaps the routing snapshot atomically; connections stay up.
	</Card>
	<Card title="Edge protection" icon="shield">
		Rate limiting built on a trusted-proxy model for the real client IP.
	</Card>
	<Card title="Observability" icon="chart">
		Prometheus metrics and structured JSON access logs.
	</Card>
	<Card title="Zero-downtime upgrades" icon="rocket">
		`raddy upgrade` hands listening sockets to a new binary without dropping
		connections.
	</Card>
</CardGrid>
